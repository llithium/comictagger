## Archive and metadata decisions (baseline 9d7d25b)

## Follow-up review and validation

- Archive publication enforces the GUI and CLI conflict policy when the copy finishes. Unique exports retry the next numbered name using the same staged CBZ. When a volume supports neither hard links nor exclusive rename, the GUI and CLI export the completed CBZ to a new sibling folder with normal directory permissions and report its path. Rewriting an existing archive preserves its file mode and, on macOS, its access control list. Direct archive API callers retain the option to replace a destination. RAR and folder copies reject members that escape the destination. Bulk tag copy still attempts other selected formats after one format fails.
- Explicit application plugin registration still takes effect when an earlier archive operation loaded the installed defaults. Filename parsing receives publisher names from the application and retains the default vocabulary for standalone callers.
